Spotify Downloader

Download a single YouTube video or load a Spotify playlist, then save the audio as MP3, WAV, or ALAC.

YouTube access

If YouTube asks you to sign in to confirm you are not a bot, sign in to YouTube in a browser on this Mac, then select it here. The app reads that browser's cookies locally when contacting YouTube.

Only the browser choice is saved. yt-dlp reads cookies into the local app when needed; the app does not create a cookie file. You can return to “No browser cookies” at any time.

Download one song

Paste a YouTube video link. Spotify sign-in is not needed. Title and artist are optional; when left blank, the app uses the video's available details.

Connect Spotify

Spotify supplies song details for WAV tags. Audio comes from the YouTube videos you select.

Load a playlist

Review YouTube matches

YouTube search starts after the playlist loads and prefers titles marked Official. Pause it any time; paste a video link to override a result. Ignore a song to exclude it from matching, downloads, and WAV tag updates. Existing files are kept.

Load a playlist to see its songs.

Download audio

Files use the name song title (artist). Playlist WAV and ALAC files include available Spotify title, artist, album, release date, track number, and genre tags.
