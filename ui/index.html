Review YouTube matches

YouTube search starts after the playlist loads and prefers titles marked Official. Pause it any time; paste a video link to override a result. Ignore a song to exclude it from matching, downloads, and WAV tag updates. Existing files are kept.

Download audio

Files are saved as song title (artist).mp3 or song title (artist).wav. WAV files receive Spotify title, artist, album, release date, track number, and available artist genre tags.

Download only audio you have permission to save. YouTube availability and match quality can vary. WAV conversion cannot add detail to a compressed source.
