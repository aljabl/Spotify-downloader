Spotify Downloader

Paste a YouTube video link to download one song, or load a Spotify playlist to find matching videos. Save audio as MP3 or WAV on your computer.

How to use it

Install and start

Unzip the download and run Start Spotify Downloader.command. The app opens in your browser and runs on your computer.

Choose a source

Paste a YouTube link for one song without signing in. For a playlist, connect Spotify and paste its link.

Download audio

Choose MP3 or WAV. For playlists, review YouTube matches and ignore songs you want to skip. Playlist WAV files include available Spotify metadata.

Requirements

Python 3.10 or newer, FFmpeg, and Deno 2.3+ or Node.js 22+. The launcher installs a pinned version of yt-dlp and its YouTube JavaScript support from PyPI.

Install dependencies with Homebrewbrew install python ffmpeg denoThen runStart Spotify Downloader.command

Audio source

Spotify provides the track list and metadata; it does not provide audio files. The local app uses yt-dlp to download audio from the YouTube videos you select. YouTube availability and match quality vary. Download only audio you have permission to save. Converting compressed audio to WAV cannot restore lost detail.
